# Security Policy

## Supported Versions

Ofan is pre-1.0 and under active development. There are no versioned releases yet.
Security fixes are applied to the `main` branch only.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report via [GitHub's private vulnerability reporting](https://github.com/ofan-lang/Ofan/security/advisories/new).
This keeps the report confidential until a fix is available.

Include:
- Description of the vulnerability and affected component
- Steps to reproduce or a minimal test case
- Potential impact

**Response time:** This is a small, pre-1.0 project maintained by one person.
We will acknowledge reports as promptly as we can and prioritize fixes for
vulnerabilities with real-world impact, but we do not offer a formal SLA or
a bug bounty program.

Once a fix is ready, we will coordinate disclosure timing with the reporter.
